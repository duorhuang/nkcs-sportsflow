## 1. 核心问题与重构目标诊断

用户在检验 V2 版本后提出了严厉批评与明确的方向指引。核心痛点聚焦在三大完全未达预期的模块：

### 1.1 风格严重“AI 化与科技风” (Aesthetic Failure)
- **用户原话**:
  > “依然没有达到我想要的艺术风格。我点进去就感觉太 AI 化了，好像所有 AI 做出来的网站都是这个样子，边缘用荧光黄、荧光绿高亮出来，像个科技风。这不是我想要的感觉，我想要的是自然风、体育风、简洁的风格。”
- **根因分析**:
  - 过度滥用 Tailwind 的高饱和度荧光色彩（`border-emerald-500/40`, `text-emerald-400`, `bg-amber-500/20`, `shadow-chiseled` 暗黑发光框、霓虹外发光环）。
  - 呈现出类似于“加密货币 Dashboard”或“科幻 HUD”的冰冷科技感，缺乏真实校园球场、更衣室战术黑板、高品质体育画报（如 The Athletic）的自然质朴与竞技温度。
- **整改目标**:
  - **彻底剔除所有荧光边缘与 AI 科技感光效**（荧光绿、荧光黄发光边框全部清除）。
  - 转向**自然风、体育风、简洁质感**：
    - 采用真实的竞技自然色系：森林墨绿草皮（Pitch Dark Green）、经典暖木色（Hardwood/Maple）、雅致深海军蓝（Collegiate Navy）、亚光温润乳白/羊皮纸色（Chalk/Parchment）、素雅哑光微边框。
    - 界面干净清爽，呼吸感强，排版紧凑专业，突出真实队员肖像、球场战术细节与严谨的训练内容。

---

### 1.2 身体形态图完全非 3D (Interactive Body Visualizer Failure)
- **用户原话**:
  > “我记得在 plan 里面说过，要用 3D、专业的身体形态，队员可以点哪里痛。但你做的纯粹是 2D 的几何图形拼凑，跟我的想法完全天差地别。”
- **根因分析**:
  - 原组件 `InteractiveBodyVisualizer.tsx` 使用了简陋的 2D SVG 几何图形（`<rect>`、`<ellipse>`）拼接人体，完全不是真实的 3D 人体模型，视觉和交互体验极其粗糙。
- **整改目标**:
  - 引入 **Three.js / WebGL 真正的 3D 竞技人体解剖交互模型**。
  - 支持 **360° 自由旋转视角 / 前后侧视角平滑切换**。
  - 精准映射运动员高发酸痛与拉伤肌群（如：大腿后侧腘绳肌 Hamstrings、股四头肌 Quads、内收肌/腹股沟 Groin、肩袖肌群 Rotator Cuff、膝关节副韧带/半月板、跟腱/小腿三头肌、腰椎核心等）。
  - 队员点击具体肌群高亮响应，动态联动右侧针对性物理疗愈、冷热敷时机与康复拉伸动作。

### 1.3 战术板操控与功能崩溃 (Tactics Board Failure)
- **用户原话**:
  > “我简单试了一下，整个战术板完全是 fail 的状态：根本不好挪动，不知道怎么加箭头，也不知道怎么移动队员，完全操控不了，非常令我失望”
- **根因分析**:
  - 缺少明确的“工具箱/模式选择栏”，用户根本不知道如何添加传球/跑位箭头。
  - SVG 拖拽坐标系换算有偏差，Pointer Capture 在部分子元素上容易丢失，导致球员移动卡顿、甚至无法拖拽。
  - 没有提供现场直观的箭头画笔功能（起笔 -> 拖拽 -> 释放成箭）。
- **整改目标**:
  - **全新重构战术板交互引擎**：
    1. 顶部/浮动常驻**六大直观操作工具按钮**（带中文与图标）：
       - 【✋ 选人移动】（直接点击/拖动任意场上球员、防守人或球）
       - 【➡️ 传球箭头】（实线金色箭头，点击起点拖至终点自动生成）
       - 【🏃 跑位路线】（虚线天蓝箭头，示意队员无球跑位）
       - 【⚡ 运球突破】（折线/波浪红橙箭头，示意持球突破）
       - 【🧹 橡皮擦】（点击任意箭头或标记即刻删除）
       - 【➕ 添加标记】（便捷添加球、防守人标记或锥桶）
       - 【🔄 一键复位 / 清空】
    2. 采用精准的 SVG / Canvas 坐标逆变换（`getScreenCTM().inverse()`），确保无论屏幕缩放、iPad 触屏还是桌面鼠标，拖拽与落点 100% 灵敏跟手，绝不丢手或飘移。
    3. 支持分阶段（Phase 1 -> Phase 2 -> Phase 3）平滑推演播放与战术卡片同步。
