# 球队战术与综合竞技管理平台（Team Tactics & Training Hub）需求记录

## 1. 需求来源
- 来源文件：`球队战术与训练管理平台（终极版产品需求规格书）.pdf`
- 用户要求：全新网站开发，中英文双语支持（i18n），面向学校所有队员和老师/教练。结合 `/plan` 与 `/grill-me` 深度调研与细化落地。

## 2. 核心架构与访问机制
- **域名与部署目标（Domain & Deployment Architecture）**：
  - 主域名：`sportsflow.best`
  - 目标业务子域名：`nkcs-sports.sportsflow.best`
  - 交付与部署流程：系统开发完成后，代码全部同步推送至 GitHub 仓库，并完整部署至 Cloudflare 托管网络（绑定子域名 `nkcs-sports.sportsflow.best`）。
- **认证与教练/队员账号规范（Authentication & Dedicated Usernames）**：
  - 纯封闭/半封闭访问，不开放给游客，统一账号密码登录。
  - **教练专有账号规范**：各大运动专区教练账号直接使用专属单字命名，简单明了：
    - ⚽ 足球主教练账号：`football`
    - 🏐 排球主教练账号：`volleyball`
    - 🏀 篮球主教练账号：`basketball`
    - 🛡️ 平台总管理员账号：`admin`
  - **队员专属账号规范**：每位队员必须拥有自己专属的正式登录用户名（在花名册后台录入时由管理员手动输入学生的真实学号或专属用户名，严禁系统后台自动粗暴拼接生成随机字符，保证每一份学生档案严肃正规）。
  - 账号跨队通用：同一账号若兼跨足球和排球，登录后可在各专区自由切换，但在各专区内的队员角色、比赛记录和花名册身份各自独立。
  - 花名册独立管理：后台设“花名册录入页（Roster Admin）”，按队伍独立管理队员信息（姓名、号码、位置、专属用户名），战术板等按队调取。
- **教练端、管理员端与队员端三重视图严格差异化设计 (Role-Differentiated Interfaces)**：
  - **队员端 (Player View - 专注学习与自我成长)**：
    - 界面极简轻量，彻底隐藏一切管理、编辑、审批与录入按钮，消除界面杂音；
    - 战术板自动聚焦于“我的任务 (My Duties)”与个人卡牌微霓虹呼吸光圈，提供纯净的步进拆解与连贯推演；
    - 训练计划纯阅读、拉伸白皮书交互自愈、比赛复盘享有 1对1 专属卡（含表现分、私密建议与已读回执）；
    - 个人中心展现多队身份、FC26 成长进度、荣誉勋章墙与专属历史复盘归档。
  - **教练端 (Coach View - 深度制作、高效调度与复盘指导)**：
    - 电脑端专属深度优化，具备全套战术绘图引擎（贝塞尔控制点、线条语义、卡牌与位置组批量调度、XY 网格）；
    - 拥有训练计划发布抽屉（含中英双语辅助翻译）、一键导出 A4 战术手册 PDF；
    - 拥有全场景随时复盘发布台（全队公开/位置小群/个人私密、1-10分评分、疲劳肌群推荐、已读回执统计）；
    - 康复技巧免审直接发布特权，以及本专区队员上传技巧的审批权限。
  - **管理员端 (Admin View - 系统基座、全域统筹与花名册分配)**：
    - 掌握全站三大运动专区全局最高权限与跨队数据；
    - 独享全局花名册录入中心（`/admin/roster`），逐个录入队员多语言姓名、号码、位置组，分配与重置账号密码；
    - 独享全局内容审核中心（`/admin/review`）与全站数据资产归档备份工具。
- **双语系统与中英专业术语对照（Bilingual i18n & Sports Glossary - 核心使命）**：
  - **核心痛点与宗旨**：许多外籍或高水平教练使用英语授课/制定战术，而部分队员英语能力有限。系统的核心使命是打破语言隔阂，让 Coach 与 Athletes 均能无缝、舒适地使用网站，确保学生彻底读懂战术意图与训练要求，让战术与训练智慧在校队中得以永续传承。
  - **全站界面与专业术语双语对照**：所有系统 UI、菜单、赛制规则、运动专业术语（如足球“High Press / 高位逼抢”、“Low Block / 低位防守”，排球“Outside Hitter / 主攻”、“Setter / 二传”，篮球“Pick & Roll / 挡拆”）均提供精准专业的中英双语切换与术语释义。
  - *(注：经明确评估，去除冗余的 Audio 语音朗读与语音输入功能，保持界面纯粹与加载极速，聚焦于高质量图文、动作卡片与视频演示)*。
- **两大核心高频仪式场景与终极使用习惯设计 (Two Core Habit Rituals - 训前确认与赛后复盘)**：
  - **核心目标**：让网站成为队员和老师“训前必看、赛后必开”的掌中心灵主场，真正融入球队的每日竞技生活。
  - **场景 A：训前 5 分钟极速确认 (Pre-Practice Ritual - 快速搞懂今天练什么与战术跑位)**：
    - **移动端首页“今日训前速览 (Today's Quick Brief)”常驻卡**：队员在去球场途中或更衣室换鞋时打开手机，登录即见今日训练时间地点、核心科目、自己的点位任务与 15 秒战术浓缩微推演，30 秒内心中有数；
    - **更衣室/多媒体教室【大屏演播模式 (Locker Room Big-Screen Mode)】**：体育老师或教练在战术室电视/智慧黑板上一键全屏演播，彻底隐藏小尺寸控件，超大标线与高反差字号，供全队围拢讲解；
    - **训前 3 分钟动态激活微清单**：一键直达今日针对性热身指引，避免热身不充分导致拉伤。
  - **场景 B：赛后即刻打开与情感共鸣 (Post-Match Ritual - 比完赛最想看复盘、荣誉与恢复)**：
    - **个人专属复盘卡的情感触达**：赛后校车上或回宿舍后，队员最关心的“教练对我今天表现怎么评价”，可在私密复盘卡中第一时间查阅 1-10 表现分、针对性鼓励与改进点，并提交【已读领悟】与【一句话自勉】；
    - **赛后智能疲劳恢复处方 (Post-Match Recovery Prescription)**：依据当场打法与出场负荷，自动开具 8 分钟恢复方案（如边后卫大腿/小腿松解，含零器械手法与水瓶替代法），加速身体恢复；
    - **FC26 竞技成长卡牌经验结算 (XP Growth Dopamine)**：每场比赛的表现转化为卡牌升级经验，累积解锁银卡拉丝与金卡号码，给队员带来肉眼可见的成长进阶喜悦；
    - **更衣室赛后影像与赛事记忆存档**：教练可上传更衣室赛后合影或短视频，将青春胜负瞬间永久封存。
  - **极致视觉与触觉舒适度 (Visual Comfort & Ergonomics)**：
    - 坚持古典暖调哑光深色质感（深墨绿草皮、暖阳枫木暗影、美式拼花硬木），杜绝刺眼冰冷的纯黑与高饱和荧光霓虹，夜间暗光查阅极其护眼柔和；
    - 移动端全触控热区严格 $\ge 48\text{px}$，单手操作防误触；正文 16px 搭配 1.6x 宽松行高，战术描述与康复指南清爽易懂。

## 3. 核心内容架构：“两本白皮书 + 一个训练计划 + 比赛中心”
1. **战术白皮书 / 战术宝典 (Tactics Playbook Whitepaper - 核心白皮书之一)**
   - **核心定位**：具备长期传承价值的“校队战术白皮书”。不仅供当期演练，更作为持久沉淀的战术资产库，供历届队员反复研读与学习。
   - **多维标签检索系统（Multi-dimensional Tagging System）**：
     - 每个战术均支持打上丰富的多维标签：
       - 【赛制/阵型标签】（如足球 7人制/11人制、排球 5-1/4-2 体系、篮球 3v3半场/5v5全场、4-3-3、2-3联防等）；
       - 【比赛情境标签（Scenarios）】（常规攻防、定位球/角球战术、领先稳守、落后绝地反击、高压逼抢等）；
       - 【赛季与年份标签】（如 2024-2025赛季、建队元老经典战术等，便于跨届传承）；
       - 【位置关注标签】（如 ST前锋关键跑位、Setter二传调度、PG挡拆配合等）。
     - 队员与教练既可通过标签点击秒级筛选，也可通过目录结构与搜索框快速检索定位，支持个人一键收藏（Bookmark）。
   - **交互式推演引擎**：
     - 赛制场地切换：足球（7人/8人/11人/自定义）、排球（标准6人制含三米线九米线轮转位）、篮球（3v3半场/5v5全场）。
     - **FIFA风格独立球员卡牌与多位置组**：
       - 每个队员拥有独立的专属卡牌（视觉质感媲美真实 FIFA 球员卡，包含队员姓名、球衣号码、专属位置标签如足球 Strikers/Center Back/后腰，篮球 PG/Center，排球 1号位/4号位等）。
       - 支持一个人归属于多个位置/组别（例如既在 Center Back 组，又在后腰组）。
       - 教练布置战术与任务时，既可以直接指定/拖入具体的个人卡牌（Specific individual），也可以直接面向一个群组（Group）批量指派。
       - 被指定的个人或所属群组队员，登录后在“我的任务（My Duties）”高亮看到针对自己的战术跑位和要求。
     - 元素：我方球员卡牌、对手“X”符号、独立球实体（Ball）。
     - 轨迹绘制：带控制点的弧线（左绕/右绕/身前绕/身后反跑），阶段位移与轨迹联动，线条语义（虚线=传球，实线=无球跑位，波浪线=带球推进，T字线=掩护挡拆）。
     - XY网格辅助：可开关网格坐标（如 A1-J10）。
     - 多阶段动画推演：Phase 1 -> Phase 2 -> Phase 3 连续平滑过渡，支持完整播放与 Next Phase 步进拆解。
     - 专项场景分类（Scenarios）：足球常规攻防/领先/落后；排球常规一传/高压一传/进攻一传及5-1与4-2轮转；篮球双后卫外线挡拆/双内线高低位配合。
     - 视频辅助与评论互动：YouTube/Bilibili 嵌入或本地视频；战术讨论区（Comments）。
     - 可选增强：轻量 AI 指令移动卡牌（预留接口）。

2. **高精度日常训练计划与动作高级卡片库 (Precision Training Schedule & Premium Drill Cards)**
   - **教练端核心指导权重提升 (Elevated Coach Authority)**：
     - 赋权教练制定高度精确、结构严密的训练课计划（Training Session），具体到“今天几点几分到几点几分练什么、每个科目练几组、每个动作的关键指令”；
     - 教练可自由调取预置动作库，或自定义创建新的【高级动作/科目卡片 (Premium Drill Cards)】，一键拼装到当日日程中。
   - **高级动作卡片结构 (Premium Drill Card Specification)**：
     - **基本信息**：科目中英文名称（如 *“3v2 快速攻防转换 / 3v2 Fast Counter-Attack Transition”*）、分类标签（热身激活 / 技战术演练 / 体能与对抗 / 专项位置技术 / 整理放松）；
     - **精准参数**：场地尺寸（如 30m x 20m 禁区前沿）、人员配置（如 6人一组：3前锋 vs 2后卫 + 1门将）、训练负荷（如 15分钟 x 2组，组间间歇 90秒）；
     - **动态演示与图解**：支持绑定高清战术走位动图、嵌入实拍教学视频或战术画板导出的微循环路线，演示极其直观可靠；
     - **教练核心指导要点 (Coaching Cues)**：提炼 3 点关键原则（如：“1. 第一脚触球向前顺步；2. 弱侧边锋反跑拉开宽度；3. 射门后必须跟进补射”）。
   - **全终端超清晰自适应呈现 (Pad / PC / Mobile Ultra-Clear Presentation)**：
     - **iPad / 平板电脑（球场边线手持神器）**：专为教练在球场边线手持 Pad 设计，大卡片、大按钮、横竖屏自适应，方便教练随时向队员展示动作演示与计时提醒；
     - **电脑大屏 (Desktop Web)**：教练排布与编辑动作卡片的主力工作台，支持从卡片库快速拖拽组装一周训练计划；
     - **手机端 (Mobile)**：队员在前往球场路上或换鞋时打开，以极具质感的卡片流形式清爽查阅，30 秒吃透今日训练科目与关键动作。
   - **纯查阅免负担**：保持纯查阅模式，无繁琐打卡负担，让注意力聚焦于战术领会与身体准备。

3. **拉伸与身体恢复白皮书 (Stretching & Recovery Whitepaper - 核心白皮书之二)**
   - **核心形态：3D 精细人体解剖可视化模型 (3D Interactive Body Visualizer)**：
     - 引入可 360 度自由旋转、缩放、聚焦的 3D 人体肌群精细模型（基于 Three.js / React Three Fiber 技术方案，辅以轻量高精度 SVG 快速切换）；
     - 细致拆解全身关键肌群与关节部位（包括：颈肩、胸肌、三角肌/肩袖、二头/前臂、背阔肌、腰椎竖脊肌、腹直肌/核心、臀肌、髋屈肌/内收肌群、股四头肌、腘绳肌、小腿腓肠肌/比目鱼肌、跟腱与足底筋膜）；
     - 鼠标悬停高亮提示，点击任意具体部位即可呼出对应部位的专业拉伸与康复指南面板。
   - **拉伸与筋膜放松全家桶覆盖**：
     - **动态拉伸 (Dynamic Warmup)**：赛前/训前神经激活与关节灵活性训练，标注动作节拍与组数；
     - **静态拉伸 (Static Stretch)**：赛后/训后肌肉降温与长度恢复，标注动作保持秒数（30-45s）与呼吸节律；
     - **筋膜枪深度冲击放松 (Massage Gun / Percussive Therapy)**：标注针对该部位推荐的按摩头类型（球形头、平头、U型头、子弹头）、振动挡位、走形轨迹、单次时长与避障禁忌（避开骨骼、大血管与关节面）；
     - **筋膜刀精准肌膜解离 (IASTM / Muscle Scraper)**：标注适合的运刀角度（30°-45°）、顺行/逆行刮拭方向、润滑介质使用与皮下充血反应应对；
     - **泡沫轴/筋膜球自重碾压 (Foam Rolling / Lacrosse Ball)**：精准指导痛点压迫与痛点定位松解技巧；
     - **零器械/简易替代方案（Zero-Cost & Minimal-Gear Substitutes - 关键兜底）**：针对无筋膜枪、筋膜刀的学生，每个部位必须提供低成本或零成本替代解法：
       1. **徒手深层按压与拨动 (Hands-on Manual Release)**：利用双手拇指指腹或指节对激痛点进行垂直深层按压（30秒持续按压与滑动拨揉）；
       2. **日常物品替代 (Everyday Substitutes)**：使用网球/棒球替代筋膜球松解足底与臀肌；使用硬质水瓶替代泡沫轴滚压小腿与大腿；使用圆润勺柄或瓷汤匙边缘（涂抹润肤乳）替代专业筋膜刀进行浅层筋膜刮拭；
       3. **毛巾/阻力带被动牵拉 (Towel-Assisted Stretching)**：利用长毛巾套在脚掌或手臂辅助进行腘绳肌、肩袖的被动渐进式拉伸。
   - **赛后/复盘专属智能康复推荐联动**：
     - 在查阅比赛或训练后的复盘反馈时，系统结合本次赛事的运动强度（如足球冲刺跑动多、排球频繁起跳扣杀拦网、篮球高频急停变向），针对性向队员推送疲劳肌群的“定制化赛后拉伸与筋膜松解组合建议”，形成训练-比赛-康复全链路闭环。
   - **UGC 全民共创与两级审核发布流 (Crowdsourcing & Review Workflow)**：
     - 初期内容由团队逐步填充，支持所有师生共同贡献（上传动作图文、示范视频、放松技巧），实现白皮书知识资产的共建；
     - **队员 (Athlete) 上传**：提交后处于待审核状态（`PENDING_REVIEW`），系统向 Admin 和 Coach 派发审核提醒（明确标明上传者、所属专区、部位与内容预览），经教练或管理员点击确认（Approve）后方可正式收录入库；若不合理可驳回（Reject）并附带修改意见；
     - **教练 (Coach) 上传**：具备专业资质背书，教练上传的内容直接免审发布（`APPROVED`），即刻对全队可见，无需再经过管理员审核。

4. **比赛计划与全场景复盘评价系统 (Match Center & Debrief / Evaluation System)**
   - **赛前与比分**：
     - 赛前日程展示（时间、地点、对手名称、关联战术白皮书中的对应战术）。
     - 极简赛后比分录入：
       - 对手信息手动录入；
       - ⚽ 足球：输入总比分 + 进球/助攻下拉选本队队员；
       - 🏐 排球：大比分 + 每局小分；
       - 🏀 篮球：全队总比分。
   - **全场景复盘评价与多级定向反馈（Flexible Anytime Debrief & Multi-Tier Targeting）**：
     - **复盘时机全面灵活**：复盘不仅局限于正式比赛，教练可随时发起复盘——可关联某场具体比赛、某次具体训练，或直接按时间日期归档（若无对应训练计划则直接记录时间），便于系统化归档追溯。
     - **建设性与私密性保护**：核心定位为保护队员自信心的建设性反馈机制，让队员清晰了解自己哪里发挥积极、哪里需要改进。
     - **多级可见范围自由指派**：教练发布复盘评价时，可自由选择发送对象：
       1. 发给全队（全队公共大群，总结整体得失、MVP荣誉等）；
       2. 发给特定位置小群（如后卫组、前锋组、二传组，针对性战术协同复盘）；
       3. 发给具体的某位队员（完全私密 1对1 评语与 1-10 表现分）。
     - **快捷选项与自由评语**：提供快捷评语标签（如“跑位积极”、“防守到位”、“注意回防保护”等）与富文本自由输入。
     - **队员端触达**：队员登录后，在个人中心和通知中接收指派给自己的复盘卡片（含所在小群或个人的专属反馈）。
     - 后续预留排行榜（Leaderboard）。
