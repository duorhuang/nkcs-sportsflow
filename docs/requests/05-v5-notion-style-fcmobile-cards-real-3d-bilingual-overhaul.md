# NKCS SportsFlow V5 核心需求重构与全维度对齐技术方案 (Notion 风格、FC Mobile 卡牌、真正 3D、全站双语、严格隔离)

## 1. 用户核心指令分析 (User Requirements Analysis)

用户在 2026-10-20 提出了 6 大明确而严格的系统目标：

1. **全站彻底双语 (Full Bilingual Support)**：
   - 网站每一处文本、按钮、标签、弹窗、发布内容（战术、训练课、复盘、康复）必须完全支持中英双语切换，绝无硬编码单语遗漏。
2. **战术板交互与多媒体发布 (Tactics Board Drawing & Multimedia)**：
   - 战术板回归高效顺畅的桌面绘图工具本质：流畅拉伸箭头（传球、跑位、运球突破）、**在球场任意点添加战术文字标注**、自由选人、拖拽、清除。
   - 战术支持多媒体：教练可撰写图文，**支持上传实拍战术照片/走位图**，以及**嵌入/上传视频**，并在战术详情页以高清晰度画廊和播放器呈现。
3. **视觉与 UI 风格重塑 (Notion-Style Aesthetics with Sports Elements)**：
   - **绝对杜绝任何荧光色**（无荧光绿、无荧光黄、无高亮发光霓虹边框）。
   - 整体风格转型为 **Notion 极简克制风**：温润素雅的深灰/浅灰底色（`#191919` / `#202020`），克制细腻的 1px 分割线，纯粹高雅的字体排版，圆角矩形 callout 块，低饱和度胶囊状态标签。
   - 在 Notion 极简骨架上注入**典雅体育元素**：自然草皮墨绿点缀、球场阵型小微缩图、真实球类触感。
4. **严格的频道隔离 (Strict Channel Isolation)**：
   - 三大运动专区（FOOTBALL / VOLLEYBALL / BASKETBALL）必须绝对隔离。
   - 足球人员（教练或队员）登录后，顶栏不出现跨运动切换器，全站任何页面、通知、赛程、战术绝不泄露篮球或排球内容。仅超级管理员具备跨项目大盘视图。
5. **队员账号与 FC Mobile 风格卡牌 (No Fake Accounts + Authentic FC Mobile Cards)**：
   - **严禁捏造假队员账号与假名字**：清空所有凭空编造的学生假账号与肖像，未录入前呈现高质感空态指引；真实队员通过花名册由教练/管理员按需手动录入。
   - **对标 EA FC Mobile / FIFA Ultimate Team (FUT) 球员卡设计**：
     - 正统盾形多边形切角卡面（Shield Geometric Cut）；
     - 顶部排布 OVR 综合评分（如 88）、位置（如 CB）、校队队徽；
     - 卡牌正中展现选手真实定妆照/剪影，下方横贯金属铭牌姓名；
     - 卡牌底部配备 6 大核心竞技属性雷达指标（PAC 速度、SHO 射门/爆发、PAS 传球、DRI 盘带、DEF 防守/拦网、PHY 力量对抗）；
     - 提供 Base Bronze（青铜）、Silver Rare（白银稀有）、Gold Star（黄金全明星）、Icon Legend（传奇名宿黑金）四阶正统游戏卡牌物理质感，彻底消除粗糙 AI 人机感。
6. **真正的 360 度 3D 人体解剖交互 (Real 3D Interactive Anatomy)**：
   - 杜绝静态平面图假充 3D。
   - 基于 Three.js 构建真正可 360° 自由鼠标旋转、滚轮缩放、俯仰倾斜的 3D 解剖人形模型，具备清晰的立体肌肉体积、光源投射与各肌群精准射线碰撞（Raycasting），并在旋转时展现真正的纵深感。
