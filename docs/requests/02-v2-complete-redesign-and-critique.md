# NKCS 球队战术平台 V2 全面重构需求与设计规范 (User Feedback & Redesign Prd)

## 1. 用户核心反馈与诊断 (User Critique & Core Diagnosis)

### 1.1 现状反馈
> “我不确定你现在是否已经把所有东西都做好了，但看完你的第一版，我只能说算是比较失望。很多东西并没有达到我的要求，也没有达到我想要呈现的状态，甚至可以说是完全没达到。特别是整个网站的很多设计方案，都不符合预期。我们还需要更加仔细地把整个网站重新做一遍。”

### 1.2 第一版差距剖析 (Gap Analysis)
1. **视觉调性与材质感严重缺失 (Lack of Tactile/Classical Heritage)**:
   - 现存版本流于普通现代暗黑后台（纯 CSS `bg-black/60`、细线 `border-white/10`、通用扁平 Lucide 图标），没有古典校队、百年常春藤/牛津剑桥竞技、物理质感、复古皮革/枫木/绿茵的光影与厚重感。
   - 缺少真实的徽章、质感相框、奖牌、纹章和实体质感。
2. **球员卡片与“游戏角色选择器”未达到预期 (Character Select Screen)**:
   - 用户期望：“如果是队员照片的话就放队员，比如下面写 center back 之类的，旁边还可以加一个 captain 的 tag... 做一个游戏的角色选择。退役的里面还可以分是‘名宿’还是只是一个普通队员。请你在网上找找那些质感的徽章，相框，和其他的好看的古典的的照片等等，然后学习或直接把它抠出来使用。”
   - 现状只是简陋列表，没有游戏化角色选择界面的沉浸感（如大尺寸卡牌、独立立体景深、金色浮雕桂冠/银色古典纹章、名宿专属暗金光环、队长金袖标浮雕）。
3. **训练卡片 (Drill Cards) 缺少演示与高级感**:
   - 用户期望：“教练端的指导权重应该也会更高一点。他们可以把具体动作做成高级卡片，所有演示都搞好，在一个 Pad 或电脑上精细地展现出来，甚至手机上都能看得清晰。”
   - 现状仅为几行文字，缺少直观的战术图解示教、动作分步示意图、球场站位与路线图示，无法满足教练在 iPad/手机上给队员一眼讲透动作的要求。
4. **战术演播室 (Tactics Board)**:
   - 缺少草皮光影、战术板物理木质边框、真实球体材质、跑位战术笔迹的专业度，大屏演播与打印白皮书需要更具质感。
5. **角色体验分离度与舒适度**:
   - 体育老师/教练端：在战术板、训练排期、比赛复盘上拥有高权重掌控力和一键广播/演示能力。
   - 队员端：赛后第一打开复盘、训练前打开确认战术、查看专属技能卡与跑位职责。

## 2. V2 重构目标与核心设计原则 (Design Principles)

### 2.1 风格定位：古典百年竞技传奇 (Classical Athletic Heritage)
- **色调体系**：
  - 足球：牛津深绿 (`#0B2418`)、古典祖母绿 (`#0E3825`)、英伦深草纹与黄铜金 (`#C69214`, `#E5B842`)。
  - 排球：经典日落暖橙 (`#9A3412`)、深红橡木 (`#431407`) 与象牙白 (`#FDFBF7`)。
  - 篮球：波士顿花园拼花硬木地板纹理 (`#2B1810`)、深干邑皮革 (`#5A2E17`) 与复古琥珀 (`#D97706`)。
- **质感要素**：
  - 物理质感相框（雕花铜边、内嵌倒角阴影、浮雕金属质感印章）。
  - 荣誉徽章体系（现役队长铜章、校队名宿黄金桂冠盾徽、毕业校友银质印章）。
  - 羊皮纸质感白皮书与古典战术夹板设计。

### 2.2 核心模块重构清单 (Action Items)

1. **真实古典质感素材与视觉资产库 (Assets & Texture Layer)**:
   - 引入高质量古典相框、浮雕金属纹章徽章 SVG / 纹理渲染。
   - 配备真实且具有古典运动质感的高清队员与教练肖像写真。
   - 真实专业战术示意图（包含球场鸟瞰、假人桩、标志碟、跑位实线/虚线剪头）。
2. **游戏级角色选择器与球员卡片 (PlayerCard & Character Select)**:
   - 具有真实厚度感与景深的高级卡牌。
   - 队长 Tag（金丝袖标/金属铭牌）、场上位置 Tag（古典铜牌）、名宿/校友 Tag（浮雕奖章）。
   - 角色选择抽屉/展示台：如同顶级体育游戏（FIFA/NBA2K/足球经理）的选人与布阵界面。
3. **教练级高级训练动作卡片 (Drill Cards with Visual Demonstration)**:
   - 每一个动作都有清晰的**战术图解演示**（包含球员动线、球路、标志桶站位）。
   - 核心教练要点（Coaching Cues）、适用年龄段（U19 深度、下探兼容 U15/U12 通俗直观）、器械与场地规格。
   - 针对 iPad、手机、笔记本的高分辨率适配。
4. **战术画板与更衣室推演 (Tactics Board V2)**:
   - 极具质感的球场草皮/木地板渲染。
   - 球员 Token 徽章化，带有球员微缩头像、球衣号码与队长光环。
   - 多阶段动画跑位轨迹平滑渲染。
5. **全流程体验优化**:
   - 体育老师/教练快速查看训练卡与战术板。
   - 队员赛前确认职责、赛后复盘分析。
