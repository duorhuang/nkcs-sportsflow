# 需求记录 08: 战术板拖拽跳边彻底修复、弧线画线、去除“乘一乘二”误解标签、全站中文与退出登录、真实肌肉 3D

**需求来源**: 用户严厉反馈与专项整改

## 1. 用户反馈核心痛点清单
1. **战术板严重 Bug**：
   - 点人依然会跳到边上去（边缘/角落），而且根本拖不动；
   - 只能画直线，无法画弧线/弯线（跑位和弧线传球受阻）；
   - 阵型发布和战术推演人位混乱，缺乏真正的战术可控性。
2. **“乘一乘二”标签误解**：
   - 之前防守人标记为 `X1`、`X2`，在中文下被看成了“乘一乘二”，极其奇怪；必须改用清晰明确的战术防守标记（如“防守1”、“防守2”或具体位置如“对方中卫”、“对方门将”）。
3. **战术文字功能粗劣**：
   - 只能弹窗手输，无法直接挑选常用的标准战术文字标签（如：高位逼抢、套边插上、倒三角回传、回撤接应、肋部穿插等）。
4. **全英文与退出登录问题**：
   - 页面出现大面积英文，队员完全看不懂；全站必须优先展示清晰纯正的中文双语；
   - 找不到或无法退出登录（Sign Out），无法切换账号和队伍。
5. **3D 人体模型问题**：
   - 需要真正展现运动肌肉轮廓的 3D 解剖形态（具备清晰腹肌、胸大肌、背阔肌、股四头肌、腓肠肌线条的运动员解剖肌肉雕塑），而不是机器人/低边形假人。
6. **整体风格不达标**：
   - 全站视觉风格需要彻底重塑，达到顶级运动品牌（Nike / Apple / Notion）干净、大气、克制的视觉设计，消除任何粗糙和不协调感。

## 2. 专项整改技术方案
1. **战术板重写**：
   - 彻底分析为什么点击会跑到边上、为什么人拖不动：直接在 HTML5 Canvas 或彻底优化的 SVG 上实现 100% 精确的 Pointer 事件，记录瞬时偏移，加入贝塞尔曲线/弧线绘制模式。
   - 彻底废除 `X1/X2`，改用专业防守标记。
   - 增加战术文字选择面板（包含足球/排球/篮球高频术语库与颜色大小定制）。
2. **导航与认证切换**：
   - 在页面顶部全局常驻：醒目的队伍快速切换器（⚽ 足球 | 🏐 排球 | 🏀 篮球）、中文/英文一键切换按钮、以及清晰可见的退出登录（登出 / 切换账号）按钮。
3. **语言本地化深度检查**：
   - 确保默认语言严格为中文（zh），所有界面文案、表单、提示、战术卡片均具备高质量中文首选。
4. **真实肌肉 3D 渲染**：
   - 构建或加载高精细度解剖肌肉雕塑模型，具备清晰可见的胸大肌、腹直肌、背阔肌、股四头肌肌肉束高光与法线凹凸细节，配合解剖光照。
