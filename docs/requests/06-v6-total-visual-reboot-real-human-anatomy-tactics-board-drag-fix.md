# NKCS SportsFlow V6: 视觉美学彻底重塑、真实 3D 人体模型升级与战术板交互完全修复

## 一、用户反馈与痛点剖析 (User Feedback & Critical Gaps)

用户在 2026-10-20 提出极为明确且尖锐的反馈：
1. **3D 人体模型失真严重**：
   - 当前 3D 模型完全是用圆柱体、球体等低级几何图元简单堆叠的“机器人/玩偶”，造型与配色极其怪异，严重缺乏人体解剖肌肉曲线与真实质感。
   - 目标：必须采用真正的 3D 人体模型（基于真实人体/运动员骨骼网格与平滑法线），具备真实的头、颈、肩、胸、核心、臀、腿部解剖体积与优雅的运动康复高亮。
2. **战术板交互与人员挪动/增删功能严重受阻**：
   - 用户无法顺畅挪动场上球员，无法加人也无法挪人，逻辑晦涩。
   - 根本原因：
     - 工具栏缺少最核心的【+ 我方队员】按钮；
     - 权限守卫过度限制了未登录或角色不匹配时的拖拽交互；
     - 必须将模式切换为特定工具才能挪人，违背直觉；
     - 缺少一键部署经典阵型（4-3-3、4-4-2 等）的实用功能。
   - 目标：
     - 白板在任何状态下均支持完全自由交互；
     - 无论当前处于何种工具，按住场上球员即可直接拖拽挪动；
     - 工具栏增加【+ 我方队员】、【+ 对方防守人】、【+ 足球/排球/篮球】、【+ 标志锥】、【+ 战术文字】；
     - 增加【一键阵型编排】快捷预设（4-3-3 / 4-4-2 / 3-5-2 / 5-1 / 1-2-2），一键摆出全队站位。
3. **视觉风格与配色彻底重构 (Zero Muddy Textures, Modern Elite Athletic Aesthetic)**：
   - 当前界面充斥着脏旧的深褐绿色重复线条底纹（`texture-pitch`、`texture-maple` 等），导致全站看起来昏暗、脏乱、陈旧。
   - 目标：彻底废除全屏重复条纹背景！
   - 采用国际顶级运动科技平台（Nike Training Club、Apple Fitness+、UEFA Champions League 战术分析大屏、Linear Obsidian Dark）标准：
     - 底色：纯净、高级、通透的黑曜曜石黑与深邃岩灰（`#0B0E14` / `#0F1218`）；
     - 卡片：微透明深色玻璃质感（`#13171F`，边框 `border-white/[0.08]`）；
     - 文字：高清晰纯白主标题与优雅钢灰副文案（`#FFFFFF` / `#94A3B8`）；
     - 战术草坪：真正专业的欧冠转播级深墨绿球场（`#15402B`）与纯白清晰标线，杜绝任何发黄、发灰的脏色。
